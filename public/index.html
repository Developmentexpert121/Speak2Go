1 · Student

Spec §3.2 · Student Object

Field names match the live users collection. The national ID is hashed into student_id before it is stored, logged, or sent to the model — the raw value never leaves this form.

2 · Exam

Spec §3.1 · Exam Object
exam_lesson flag: spec §2 routes lessons "flagged with the Exam parameter" to this module, but no such flag exists in lessonDefinitions — exam, isExam, exam_lesson and examLesson all match zero documents. Anything reaching this module was routed deliberately, so exam_lesson is recorded as 1 (assumed) until Speak2Go adds the field.

3 · Student answers

One slot per exam question. Leave a slot empty and it is treated as unattempted — it forfeits its points rather than being dropped from the total.

4 · Part C reference clip

phases.Conversation.videoPath

Transcript of the clip the student watched, used as ground truth when scoring Part C content accuracy. In production the clip comes from lessonDefinitions.phases.Conversation.videoPath, present on 140 of 160 COBE/Boost lessons — transcribing it automatically is the remaining piece here.

5 · Run evaluation

Calls Deepgram + OpenAI for every answer — this costs API credits and takes a few minutes.
